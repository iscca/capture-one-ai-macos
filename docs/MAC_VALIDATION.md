# macOS 本机验证记录

更新：2026-10-29。环境为 arm64、macOS 27.2、Capture One 16.8.6.25、Python 3.12.14；两个 Session 中的 TIFF 和 DNG，测试样本处理引擎 1300。以下是代表性实际验证，不承诺所有照片、参数组合、处理引擎或其他版本均通过。

所有写测使用登记候选。原变体与已经交付的 Portra 调色版本保留。详细收据、照片、参数快照和实际 JPEG 预览只存在本机私有状态目录；公开仓库不包含私人路径、UUID 或图片。

## 本机失败并停用

- 图层 `move`：通用移动调用曾移除一个刚创建的测试空层；已保留原错误与实际状态核对记录。带明确插入位置的调用在本版本也未产生符合请求的重排。现在在派发前拒绝，不再作为可用排序功能。
- 图层 `duplicate`：宿主返回未识别消息，没有创建新层；已按原请求只读核对。现在在派发前拒绝。
- Skin、Advanced 反选、线性/径向渐变、蒙版组合、子蒙版选择、灰度蒙版像素：缺少当前已接入的原生入口，明确不可用。界面辅助按用户要求暂停。
- 白平衡“恢复相机中性默认值”没有对应的模块重置入口；可粘贴先前读取的完整白平衡快照。

## 本轮修复

1. 新增结构化模块 `film_grain`，六种类型、impact/granularity 0..100；沿用同一 Core、候选限制、目标与前态保护、request_id 和操作收据。
2. all 范围的导航凭据检查改为重新读取同一个范围，避免错用 filtered 清单判定过期。
3. 修复导出队列竞态：不再逐个读取可能已出队的 job 对象 ID，改用原生批量 ID；同时等待本次预期文件出现。
4. 对结果未知的导出，只有原变体的 C1 输出历史、时间和预期私有 JPEG 同时匹配，才记录“导出确已发生”；不声称当前调整版本已验证，不重发原请求。
5. 后续导出只清理私有预览目录中有已完成输出历史、且没有排队任务的遗留临时配方。
6. `context.capabilities` 增加本机验证范围和可用动作；实际失败的排序/复制明确关闭。版本不匹配时不继承验证结果。
