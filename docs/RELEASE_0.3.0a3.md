# 0.3.0a3 / v0.3.0-alpha.3

本版本将摄影师修图任务、参考照片追色及固定细节颜色分析加入 Mac 完整包与独立 skill 包。
仍为实验性预发布；已有实机范围为 Apple Silicon、Capture One 16.8.6.25 和 Session。

## 新增与改善

- 保存修图目标、需要保护的颜色和细节；保留原版本，在登记候选上继续调整。
- 保存 C1 实际预览检查点，比较起点、上一轮及已认可版本，记录反馈和局部认可。
- 将参考图拆成可跟踪的影调及颜色目标，区分整体改善、保持的部分、退化与不确定项。
- 分析暗部、中间调和高光中的颜色倾向，比较成对固定细节的明度、色相及浓淡差异。
- 参考图片按色彩配置处理，保留参考图有意的灰度偏色，不将测量值直接当成 C1 滑块参数。
- 首页改为参数用途与参考追色流程说明，配套 skill 增加详细分析和复核方法。

## 下载与更新

- `CaptureOne-AI-macOS-Experimental-0.3.0a3.zip`：本机程序、安装入口、文档和配套 skill。
- `capture-one-edit-0.3.0a3.zip`：独立 skill；仍需安装本机程序并连接支持图片的 AI 客户端。
- `SHA256SUMS.txt`：两个 ZIP 的 SHA256 校验值。

更新旧版时同时更新程序和 skill，保留本机运行状态；先核对未完成操作，再刷新客户端连接。
按 [安装说明](INSTALL.md) 使用，不覆盖或重新分发旧版 ZIP。此版本不包含独立 ChatGPT 插件包。

## 验证与限制

本轮为版本和分发更新，不修改调色执行逻辑。此前相关检查 105 passed、1 个已退役 recover 接口旧测试排除；
这不是全仓全部历史测试通过的声明。任务、反馈、实际预览、参数恢复和颜色分析的证据分别见
[P0 验证](P0_VALIDATION.md)、[P1 验证](P1_VALIDATION.md) 与 [固定细节分析](REFERENCE_MATCHING.md)。

本次打包不自动调整照片、不切换 Session，也不为发布重新生成照片预览。
跨场景追色、人像和产品颜色仍需摄影师实际验收。固定细节测量基于渲染图片，不代表相机校色、精确像素锁定或印刷验收。
参数恢复仅覆盖快照所在层的调色参数，不包含完整图层/蒙版历史。

批量处理暂缓；Skin 专用参数、图层排序/复制、渐变/组合/子蒙版、蒙版像素、预览到 RAW 坐标映射和无导出渲染仍不可用。
照片、预览、私人路径/配置、候选资格、令牌和操作数据库不随包分发。
