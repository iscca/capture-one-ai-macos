# Mac 导航与预览

images(action=list) 枚举当前集合，scope=filtered 或 all，返回照片标识、分页及集合凭据。分页沿用同一 collection_token；切图使用新鲜列表观察，variant_uuid 使用宿主返回的标识，不自行构造。导航后重新读取照片再编辑。

## 实际预览

当前使用 kind=render，经用户明确授权并配置临时低分辨率 JPEG 导出后，取得 Capture One 当前调整后的实际输出。max_size 为 128..1600。MCP 返回 JPEG 图片块，CLI 返回本机路径。

后台队列与预期输出文件均核对；导出前后检查当前目标及已暴露的参数状态。超时或结果未知先查询原请求，不换编号重复导出。仅在原变体输出历史、时间和预期文件均匹配时核对“导出已发生”，不据此承诺当前修订已通过视觉验收。

不提供无导出原生预览、直接灰度蒙版缓冲或 preview↔RAW 坐标映射。RAW 内嵌 JPEG 不包含当前 C1 修改，不能作为编辑后预览。

缓存只保留最近八份成功预览；重要前态由客户端留存在本机。缩图颗粒效果不代表原尺寸检查通过。未收到或实际查看图片时，说明视觉验证缺口。
