## 代表性本机验证

Capture One 16.8.6.25、Apple Silicon、用户指定 Session 中单选的一张 DNG。
先只读检查，用户重新单选后才继续；创建一次登记候选，不写原版本。

1. 从原版本取得 C1 实际 1600px JPEG，实际查看，作为同照片的功能测试参考。
2. 保存两个参考特征：受光墙面/锈金属的暖光关系，以及较克制的植被绿色。
   明确这是同照片对应关系测试，不能代表跨场景复刻。
3. 创建并绑定登记候选，取得候选调整前实际预览。
4. 保存明确标注“开发功能测试，非用户审美反馈”的结构化反馈，关联调整前检查点；
   使用 Basic 绿色区，将饱和度降低 6 个 C1 单位，回读并生成实际预览。
5. 新检查点冻结两个参考目标、一个反馈及两个保护项。实际查看前后画面，观察到轻微绿色变化，
   记录两个 target_results、两个 protection_results 和一个反馈 resolved 结果。
   这些是客户端视觉判断，没有伪造用户整图或局部认可。
6. 恢复起点快照，重新渲染并实际查看；本例解码 RGB 与起点完全相同：平均绝对通道差 0，最大差 0。
7. 切回原版本，脚本可见修订指纹与测试前相同；测试任务停止、测试候选保留，没有未决操作。
8. 在无未决操作时只重载本项目执行桥。实际 MCP stdio 列出六工具，暴露 reference_plan/recognize，
   context 返回四项 P1 能力；按两个历史检查点比较，取得两个图片块、交付均 available，
   保留两个参考结果及一个反馈结果，无 MCP 错误。
