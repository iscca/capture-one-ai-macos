# Mac 支持范围

已在 Apple Silicon、macOS 27.2、Capture One 16.8.6.25、Session 中进行代表性真实读写、回读、预览与恢复。其他版本、Intel、Catalog、跨文档和批量任务未完成资格验证。

已通过的模块及具体限制见 [MAC_VALIDATION](MAC_VALIDATION.md)。安装见 [INSTALL](INSTALL.md)，功能入口见 [MACOS](MACOS.md)。

- 基础调色、曲线、色阶、Basic/Advanced、色轮和背景层颗粒。
- 全局及局部代表性操作，受限图层与 AI 蒙版、复制/羽化/亮度范围。
- 集合导航、原请求去重、目标及前态检查。
- 用户明确启用的实际 JPEG 预览和 MCP 图片块。

未提供 Skin 逐项参数、排序/复制图层、渐变/组合/子蒙版、蒙版像素、坐标映射或无导出渲染。清晰度、锐化、降噪、镜头/几何和人像精修不自动纳入调色。

没有承诺所有照片、相机、参数组合、AI 分割或导出色彩管理均经过验收。单元测试不替代宿主实机证据；本机版本验证不适用于其他构建。
