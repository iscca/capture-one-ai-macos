# Windows 验证范围与限制

Mac 实验实现单独见 [MACOS](MACOS.md) 和 [MAC_VALIDATION](MAC_VALIDATION.md)，不继承下列 Windows 结果。

截至 2026-10-29，Windows / Capture One **16.8.6.3784** / 一个 Session，以真实 RAW 的登记候选变体进行读、写、回读和预览。本机结果不表示官方支持或所有照片、版本都通过。

| 模块 | 本机实测 |
|---|---|
| 曝光／白平衡／HDR | 10 项全局参数，主体层代表性修改通过 |
| 色阶 | RGB/R/G/B，输入输出端点和中间调通过 |
| 曲线 | 五通道控制点原生写入回读；真实秋日调色用全部五通道并看预览 |
| Basic | 八色区和全部颜色通过；真实照片黄绿、橙红修改并看渲染 |
| Advanced／Skin | 增删、RGB/HSL、平滑度、范围、启用/反选；肤色三项均匀度通过 |
| 色轮 | 主轮 X/Y 和其他三轮 X/Y/亮度；真实照片三向分级并看渲染 |
| 图层 | 创建、选择、透明度、改名、开关、复制、排序、自建层移除 |
| 蒙版 | 主体/背景 AI、反相、复制、组合、羽化、填充/清除、线性/径向渐变、亮度范围、子蒙版选择 |
| 复用 | 七个模块的默认值重置和读取快照粘贴 |
| 导航 | 179 个变体集合完整枚举、分页、UUID 跨照片选择、上/下一张 |
| 预览 | 原生照片/灰度蒙版，过期版本拒绝，preview↔RAW 映射 |
| MCP | 标准 SDK 验证六工具、workflow/guidance、PNG 图片块；CLI 同核心 |

本机性能样本：代表性修改回读约 0.12～0.21 秒；1200 像素长边修改后预览约 0.13 秒，完整 MCP 图片回传约 0.23 秒。AI 蒙版、冷缓存、大 RAW 及负载会改变耗时，不能承诺普遍速度。

此前开发阶段有两名独立审阅者复核及副本实测；不把历史审阅说成本次发布又做一轮。打包只追加分发文件、安装入口和必要检查，不重跑所有参数组合。发布检查见 [RELEASE_CHECKS](RELEASE_CHECKS.md)。

公开包排除私人照片、会话路径、UUID 和完整操作记录，这里是范围摘要，不是可供外部复算的图像数据集。

## 尚未覆盖

- 其他 C1 版本、Catalog、多实例、跨文档；升级需重新核对内部对象。
- 多照片批量编排；当前可逐张操作，不承诺原子批量编辑。
- 全尺寸导出、完整配方验收、独立 ICC 色彩准确性验收。
- 每种相机 RAW、所有蒙版／参数组合、64 点曲线极值。
- 清晰度、锐化、降噪、镜头／几何和人像精修。
- 每个第三方 AI 客户端逐一验收；协议通用不等于客户端都会正确传图。

内部原生对象不是官方公共 API。读写使用 C1 getter/setter、Undo/通知和内核，不写数据库／侧车文件或进程内存地址。保留的显式 UI 兼容入口不改变默认原生路线。
